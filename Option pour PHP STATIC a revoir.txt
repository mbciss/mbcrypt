Il existe 3 approches sans toucher au code appelant :

  ---
  Option A — Variable d'environnement (déjà supporté, zéro modification)

  C'est déjà codé dans l'extension (getenv("MBCRYPTLOAD_PASSWORD")). Il suffit de définir la variable avant de lancer PHP :

  set MBCRYPTLOAD_PASSWORD=mon-mot-de-passe
  php encrypted.php          ← fonctionne directement

  Côté serveur web (Apache / Laragon) :
  SetEnv MBCRYPTLOAD_PASSWORD "mon-mot-de-passe"

  Avantage : zéro modification. Inconvénient : variable visible dans phpinfo() et les outils système (ps, Task Manager).

  ---
  Option B — Directive php.ini dans l'extension (modification mineure)

  Ajouter une entrée INI à l'extension : mbcryptload.password = "...".
  PHP lit la valeur au démarrage, avant toute exécution de script.

  ; php.ini
  extension=php_mbcryptload
  mbcryptload.password = "mon-mot-de-passe"

  Ensuite php encrypted.php fonctionne directement, sans rien écrire dans le code.

  Avantage : propre, transparent, standard (même mécanique que opcache.enable, etc.). Inconvénient : mot de passe en clair dans php.ini — à protéger
   en lecture (chmod 600 sur Linux, ACL sur Windows).

  ---
  Option C — auto_prepend_file (zéro modification de l'extension)

  PHP permet d'injecter automatiquement un fichier avant chaque script via php.ini :

  ; php.ini
  auto_prepend_file = "C:/chemin/boot.php"

  <?php
  // boot.php — non chiffré, protégé en lecture seule
  mbcryptload_set_password("mon-mot-de-passe");

  Tout fichier chiffré appelé directement (CLI ou HTTP) bénéficiera automatiquement du mot de passe.

  Avantage : zéro modification de l'extension, fonctionne aujourd'hui. Inconvénient : fichier boot.php physique à protéger.

  ---
  Comparatif

  ┌──────────────────┬─────────────────┬───────────────┬────────────────┬──────────┐
  │                  │ Modif extension │ Modif php.ini │ Fichier extra  │ Sécurité │
  ├──────────────────┼─────────────────┼───────────────┼────────────────┼──────────┤
  │ A — env var      │ aucune          │ aucune        │ non            │ faible   │
  ├──────────────────┼─────────────────┼───────────────┼────────────────┼──────────┤
  │ B — INI entry    │ mineure         │ oui           │ non            │ moyenne  │
  ├──────────────────┼─────────────────┼───────────────┼────────────────┼──────────┤
  │ C — auto_prepend │ aucune          │ oui           │ oui (boot.php) │ moyenne  │
  └──────────────────┴─────────────────┴───────────────┴────────────────┴──────────┘

  Recommandation : Option B si vous voulez quelque chose de propre et intégré à l'extension. Option C si vous voulez zéro recompilation.
