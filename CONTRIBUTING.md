# Contributing

1. Open an issue describing the bug or feature first.
2. Fork, create a branch, keep changes focused.
3. Build and test with the scripts in `build/` and `test/` (see `build/GUIDE-COMPILATION-*.md`).
4. Open a pull request describing what changed and how you tested it (PHP version, OS, NTS/ZTS).

By contributing you agree your contribution is licensed under GPL-2.0, like the project.
